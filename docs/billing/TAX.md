# Tax

## What the code does

| Aspect | Fact |
|---|---|
| Tax source | One toggle: `STRIPE_AUTOMATIC_TAX === "true"` becomes `deps.automaticTax`, passed as `automatic_tax: { enabled }` when creating the Checkout Session (`stripe/real.ts`) |
| Default | Off (variable unset) |
| Hardcoded tax | None. No rates, no country logic, no VAT number, no tax text anywhere in billing code. The plan is `2500` minor units USD; tax, if enabled, is added by Stripe on top |
| Address collection | `billing_address_collection: "auto"` |
| Stored | `billing_invoices.tax_minor` mirrors Stripe's `total_taxes` sum; `current_effective_amount_minor` and `next_expected_charge_minor` are **before tax** (`subtotal - discount`), and the Billing page labels amounts "before tax" |
| Quote on the pre-checkout page | Informational, before tax; the Stripe invoice is authoritative for what is charged |
| Invoice document and numbering | Stripe-hosted; `invoice_number` is Stripe's, never generated by InnerDweS |

## Rules

- Exactly one tax source: Stripe Tax. Do not add application-side tax math.
- Do not turn `STRIPE_AUTOMATIC_TAX` on until the operator and registrations are decided and Stripe Tax is configured for the account (tax origin address, registrations, product tax code).
- The Test-mode and Live-mode Stripe tax settings are separate; configure each.

## Open decisions (blockers for paid launch)

| Decision | Owner | State |
|---|---|---|
| Legal operator / seller of record | Owner | Undecided |
| Invoice issuer details | Owner | Undecided (follows operator) |
| Jurisdictions where tax is registered and collected | Owner / tax adviser | Undecided |
| Tax-inclusive vs tax-exclusive pricing presentation (current copy is "before tax") | Owner | Undecided |
| Product tax code for a SaaS subscription | Owner / tax adviser | Not set |
| Whether `$25` must display per-country tax-inclusive pricing | Owner | Undecided |
| Customer tax ID collection (B2B) | Owner | Not implemented in Checkout config |
| Metrics and MRR are pre-tax (METRICS.md) | - | Decided in code |
